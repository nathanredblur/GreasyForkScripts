# GreasyForkScripts
My collection of user scripts for Tampermonkey et al.

## Installation

Install [Tampermonkey](https://www.tampermonkey.net/) (or Violentmonkey) and open the script's install link. Scripts with an `@updateURL` update automatically from this repo when their `@version` changes.
